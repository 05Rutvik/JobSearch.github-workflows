# My Daily Jobs

One-time setup (5 min):
1. Create a new **public** GitHub repo, upload all files here (keep the `.github/workflows` folder).
2. Repo → Settings → Pages → **Source: GitHub Actions**.
3. Repo → Actions tab → "Daily jobs" → **Run workflow** (first run takes ~5-10 min).
4. Open `https://<your-username>.github.io/<repo-name>/` — bookmark it.

It then refreshes by itself every day at 8:00 AM IST.
Change searches, companies, keywords: edit `config.yaml` only.
